# 金取引お天気：セットアップ手順（スマホだけで完結）

毎朝7時（日本時間・月〜土）に、金の1日の危険予報が Discord に届くようになります。
サーバー・パソコンの常時起動は不要。GitHub の無料自動実行機能（Actions）で動きます。

## 届く内容（デモ）

```
⛈ 金取引お天気 8/7(金) 07:00
総合: 嵐（大荒れ警戒日）

【今日の空模様】
・ボラ水準: 高め（GVZ 24.8 / 過去78%タイル）
・今日の想定変動: ±1.56%が目安 ≒ ±$52
・大口の混み具合(参考): 87%タイル → 買いが混雑。量を控えめに
・金ETFマネー: 直近5日 +8.4t の流入

【重要発表（🚫=前後15分は新規禁止）】
🚫 8/7(金) 21:30 Non-Farm Employment Change
・ 8/12(水) 21:30 CPI m/m

【ヒゲ注意ゾーン（損切りを置かない場所）】
・3350(キリ番) / 3368(前日高値) / 3322(前日安値)
```

## 設定手順（3ステップ・10分）

### ① Discord で「届け先」を作る

1. Discord アプリで自分用サーバーを作成（＋ボタン →「オリジナルの作成」）
2. サーバー設定 → 連携サービス → ウェブフック →「新しいウェブフック」
3. 「ウェブフックURLをコピー」を押す（このURLは秘密。人に見せない）

### ② GitHub にそのURLを登録する

1. このリポジトリのページ → Settings → Secrets and variables → Actions
2. 「New repository secret」を押す
3. Name: `DISCORD_WEBHOOK_URL` ／ Secret: さっきコピーしたURL → 保存

### ③ 自動実行をONにする

1. リポジトリの「Actions」タブを開く
2. 有効化を求められたら「I understand… enable them」を押す
3. 左の「gold-weather」→「Run workflow」で手動テスト実行
4. Discord に届けば完了。以後は毎朝7時に自動で届く

## 使っているデータ（すべて無料・鍵不要）

| 項目 | 出どころ | 更新 |
|---|---|---|
| ボラ水準・想定変動 | CBOE GVZ（金の恐怖指数）via FRED | 毎日 |
| 大口の混み具合 | 米当局CFTCの週次報告 | 週1・3日遅れ |
| 金ETFマネー | GLD公式の保有量CSV | 毎日 |
| 発表予定 | ForexFactory 週間カレンダー | 毎日 |
| 前日高値安値・キリ番 | Stooq の日足 | 毎日 |

一部の取得に失敗した日は、その項目を欠いたまま残りだけで配信されます（全滅はしない設計）。

## 正直な注意書き

- **方向（上がる/下がる）は永久に言いません。** これは危険予報であって売買指示ではありません
- 「大口の混み具合」の警告しきい値は**まだ過去データでの有効性検証（本体計画のH1）を通していない参考情報**です。検証が済んだら数値の意味が確定します
- 発表イベントの「過去◯倍動いた」という実測値は Phase 1（イベント統計エンジン）完成後に追加されます。現在は発表の有無と時刻のみ
- 配信時刻の朝7時・時間帯メモは夏時間基準です。11月〜3月は米国の冬時間で発表が1時間遅くなります（例: 21:30→22:30）。冬時間対応は今後の改修項目
